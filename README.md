## 🔐 Cybersecurity Roadmap — Days 1–15

| Day | Main Topic | What I Learned |
|---:|---|---|
| 01 | 🐧 Linux Foundations | Kali Linux, terminal basics, filesystem, and essential commands |
| 02 | 🐧 Linux Practice | Files, directories, permissions, `chmod`, `find`, `ps`, `top`, `tree`, and `apt` |
| 03 | 🌐 Networking Basics | IP addresses, `ip a`, routing, DNS, `ping`, ports, `ss`, and private vs public IP addresses |
| 04 | 🔗 Network Protocols | OSI and TCP/IP models, TCP vs UDP, TCP handshake, HTTP/HTTPS, SSH, DNS, and MySQL |
| 05 | 🌍 HTTP Fundamentals | HTTP/HTTPS, methods, status codes, headers, cookies, URLs, and request/response structure |
| 06 | 🧩 Web Fundamentals | HTML and DOM basics, elements, attributes, `id` vs `class`, and how browsers interpret webpages |
| 07 | 🔎 Browser DevTools | Network tab, requests, status codes, content types, JavaScript files, and CORS basics |
| 08 | 📨 HTTP Deep Dive | HTTP/2 pseudo-headers, query parameters, JSON, referrer policy, and CORS |
| 09 | 🛡️ Burp Suite Proxy | Proxy setup, interception, HTTP history, Forward, Drop, `127.0.0.1:8080`, and request inspection |
| 10 | 🔁 Burp Repeater | Modifying and resending requests, parameters, response comparison, and baseline testing |
| 11 | 🔐 Authentication and Sessions | Authentication vs authorization, sessions, cookies, session IDs, `Set-Cookie`, `HttpOnly`, `Secure`, and `SameSite` |
| 12 | 🚪 Access Control and IDOR | Access control, IDOR, BOLA, object identifiers, and authorization checks |
| 13 | 🛡️ OWASP Top 10 | Major web-vulnerability categories and how to recognize them |
| 14 | 💉 SQL Injection | SQL, SQLi concepts, parameters, baselines, common SQLi types, Repeater testing, and prepared statements |
| 15 | 🕸️ Cross-Site Scripting | Reflected, stored, and DOM XSS; sources, sinks, output encoding, and Content Security Policy |

> All cybersecurity learning and testing is limited to legal labs, CTFs, intentionally vulnerable applications, and systems for which I have explicit permission.
