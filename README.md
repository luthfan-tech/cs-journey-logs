## 🔐 Cybersecurity Roadmap — Days 1–15

| Day | Main Topic | What You Learned |
|-----|------------|------------------|
| 01 | 🐧 Linux Foundations | Kali Linux, terminal basics, filesystem, commands |
| 02 | 🐧 Linux Practice | Files, directories, permissions, `chmod`, `find`, `ps`, `top`, `tree`, `apt` |
| 03 | 🌐 Networking Basics | IP addresses, `ip a`, routes, DNS, `ping`, ports, `ss`, private/public IPs |
| 04 | 🔗 Network Protocols | OSI model, TCP/IP model, TCP vs UDP, TCP handshake, HTTP/HTTPS, SSH, DNS, MySQL |
| 05 | 🌍 HTTP Fundamentals | HTTP/HTTPS, methods, status codes, headers, cookies, URL, request/response structure |
| 06 | 🧩 Web Fundamentals | HTML/DOM basics, elements, attributes, `id` vs `class`, how browsers interpret webpages |
| 07 | 🔎 Browser DevTools | Network tab, requests, status codes, content types, JavaScript files, CORS |
| 08 | 📨 HTTP Deep Dive | HTTP/2 pseudo-headers, query parameters, JSON, referrer policy, CORS |
| 09 | 🛡️ Burp Suite Proxy | Proxy, interception, HTTP History, Forward, Drop, `127.0.0.1:8080`, request inspection |
| 10 | 🔁 Burp Repeater | Modify/resend requests, parameters, response comparison, baseline testing |
| 11 | 🔐 Authentication & Sessions | Authentication vs authorization, sessions, cookies, session IDs, `Set-Cookie`, `HttpOnly`, `Secure`, `SameSite` |
| 12 | 🚪 Access Control & IDOR | Access control, IDOR, BOLA, object identifiers, authorization checks |
| 13 | 🛡️ OWASP Top 10 | Major vulnerability categories and how to recognize them |
| 14 | 💉 SQL Injection | SQL, SQLi, parameters, baselines, SQLi types, Repeater testing, prepared statements |
| 15 | 🕸️ Cross-Site Scripting | XSS, Reflected/Stored/DOM XSS, sources, sinks, output encoding, CSP |
